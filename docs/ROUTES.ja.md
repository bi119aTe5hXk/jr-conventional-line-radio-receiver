# 路線から受信チャンネルを選ぶ

[English](ROUTES.md)

チャンネル一覧の上にある「路線から選ぶ」から、周波数設定を開かずに受信対象を指定できます。

1. 会社・プリセットを選び、路線名・区間の駅名・D番号で検索します。空白で区切ると絞り込みになり、全角英数字も使えます。
2. 区間を1つ以上チェックします。検索しても選択済みの区間は確認欄に残ります。「解除」で個別に、「選択を解除」でまとめて外せます。
3. 音声・データ波の周波数を確認します。重複する周波数は1波にまとめます。「旅客一斉情報も受信」は、そのプリセットに共通波がある場合に初期状態でオンになります。JR 東日本の運行把握モニタにも必要な波です。
4. 適用すると、現在の受信対象を確認欄の周波数に**置き換えます**。キャンセル・Escapeでは変更しません。別のプリセットに切り替える場合は、既存のプリセット選択と同様に中心周波数・推奨レートも切り替えます。IQ WAV の入力設定は変更しません。
5. 「受信を開始」で受信します。受信中も路線表を参照できますが、受信対象の変更には停止が必要です。

手動で選択した音声チャンネルは、切替先のプリセットにも同じ周波数があれば維持します。受信対象の指定によって音声の自動選択がオンになることはありません。周波数ごとのチェックボックスで追加・調整することもできます。受信対象が適用時のままであれば、ダイアログを開き直したときに前回の区間選択を復元します。下書き・受信対象のチェック状態はアプリ再起動後には引き継ぎません。

## 外部プリセットへの追加

既存のバージョン1 JSONの各 `channel_sets` に、省略可能な `routes` を追加できます。路線情報がない既存ファイルも有効で、周波数の手動選択をそのまま利用できます。[JSONスキーマ](../config/radio-presets.schema.json)と[英語版のメタデータ例](ROUTES.md#external-preset-files)を参照してください。例は既存のチャンネル定義へ追加する情報であり、単独では読み込めません。

- 路線IDは、同じチャンネル定義の `routes` 内で重複できません。
- `voice_hz` は第1波・第2波の順に異なる整数周波数を2つ指定し、`service: "voice"` のチャンネルを参照します。`data_hz` は `service: "data"` のチャンネルを参照します。`note` は省略可能です。
- プロファイルが3波すべてを含む場合にのみ、その路線を選択できます。旅客一斉情報は別に追加します。
- 1つのチャンネル定義につき路線512件までです。不正な路線情報がある場合はファイル全体の読み込みを拒否し、使用中の設定を維持します。

受信停止中に外部ファイルを再読み込みすると、周波数と路線の変更が反映されます。
